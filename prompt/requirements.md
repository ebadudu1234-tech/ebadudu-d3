# D3（direction 3）要求汇总

最后更新：2026-10-11

> D3 从 0 开始做，**不用 D1 / D2 的代码和样式**（只复制了作品图片、作品数据）。
> 要求：根据我做过的作品分析我的个人风格，做得**有意思、好玩一点**，学习 `prolilab/references` 笔记里的交互方式和动画方式。

## 1. 个人风格分析（从作品里看出来的）

| 看到的东西 | 来自哪些作品 |
|---|---|
| **玩具、角色、吉祥物** | 小物件架子、青蛙、Yiwugo 的蜜蜂、Code For Fun 的机器人、statement 里的 "toy energy" |
| **糖果色、高饱和** | Ungreen Shop 的粉紫泡泡、Code For Fun 的青蓝紫黄方块、5:50 的彩色瓷砖、Sónar 的发光蓝 |
| **鼓起来的 3D / 泡泡字、像素字** | Ungreen Shop 的充气字、Code For Fun 的 PIXEL LAB、2000s Game Zine 的像素标题 |
| **游戏** | Allodox、2000s Game Zine、毕业设计做的游戏 |
| **拼贴、超现实的混搭** | After Dada、DADA Newspaper、Under the Cyber Skin、Modular Typefaces |
| **好玩的外表下有清楚的系统** | 模块字体、导视系统（Yiwugo）、信息设计、"Let me guide you" |

老师给的三个词：**technical（技术）、flavorful（有味道）、energy（能量）**；联想到的颜色是**黄色**。

**一句话：** 用玩具一样的快乐能量，把东西做得一眼就懂、像在玩 —— 所以 D3 是一个**"玩具箱"**。

## 2. 视觉系统（现代为主，少量复古元素）

> 第一版用粗黑描边、硬阴影、泡泡字 + 像素字，你说**太丑、要现代一点**；**可以有复古元素，但不能整个页面都是复古感**。所以改成：

- **字体**：**Geist**（现代无衬线，大标题字距收紧）+ **Geist Mono**（小标签、编号）。**像素字 Silkscreen 只用在少数复古点缀上**：首页 / About 的黄色警示贴纸 "WARNING: I RUN ON TOY ENERGY"、扭蛋开场的计数、导航下面的 "YOU ARE HERE"。
- 首页的黄色贴纸现在是 VIEW ALL MY WORK（About 页的 WARNING 贴纸不变）。
- **颜色**：暖浅灰底 `#F2F1ED`、白色卡片、近黑 `#0E0E0E`、灰 `#8A8A85`；**玩具黄 `#FFD84D` 只做小面积点缀**（圆点、高亮、下划线、当前页标记）。标签用小彩点（粉 / 蓝 / 绿 / 橙 / 紫 / 黄）区分，不再整块填色。
- **形状**：不用粗描边和硬阴影；**白色圆角卡片（22px）+ 柔和阴影**，细线分隔；导航是毛玻璃胶囊。
- **动效**：弹簧感（会过冲再回弹）用在"会动的东西"上：玩具掉落碰撞、玩具跳一下、卡片浮起、扭蛋裂开；页面之间深色面板滑过。系统开了"减少动态效果"时关掉。
- **光标**：小黑色名牌（像 Figma 多人光标），前面一个黄点，显示鼠标下面是什么。

## 4. 页面

- **index.html**：扭蛋开场（数字数到 100，扭蛋摇两下裂开，可跳过，每次访问一次）→ 玩具箱（整屏、不滚动）：大字 EBADUDU 每个字母轻轻浮动，下面是黄色复古贴纸 **VIEW ALL MY WORK**（原来是 WARNING 贴纸，按要求换成了这个；**放大三倍**：电脑上字 39px，手机上按屏幕宽度缩到 18px，在大字下方不重叠；点它进入 WORK 页，在玩具上面不会被挡住，鼠标碰到会摆正放大）；20 个作品小物件从上面掉下来。
  - **玩具只能玩，不链接到任何作品**（首页唯一的出口是 VIEW ALL MY WORK 贴纸和顶部导航）：可以抓起来、拖动、扔（手机用手指），SHAKE THE BOX 让所有玩具跳起来；鼠标停在玩具上光标显示作品编号和名字（只是名字，点了不跳转）。提示文字：GRAB · THROW · STACK。
  - **物理用 Matter.js**（cdnjs 0.19.0）：每个玩具的**碰撞形状是从它自己图片的不透明像素描出来的外轮廓**（凸包），所以碰到的位置就是看到的位置，可以叠起来；静止的玩具会"睡着"，不会在上面一直转。固定步长计算，屏幕刷新率不同也一样稳。玩具大小随屏幕变化。（第一版是自己写的圆形碰撞，上面的玩具会一直转，已替换。）
- **work.html**：大标题 The Shelf + SHELF / INDEX 切换（记住上次的选择）+ 一句话筛选（选中的词下面有黄色高亮）。
  - SHELF：每个年份一层架子（细线 + 柔和阴影），玩具站在上面、下面是作品名和编号；鼠标碰到玩具会跳一下；一层放不下时左右滑动。
  - INDEX：表格（№ / 作品 / 类别 / 年份），鼠标所在行变白，旁边跟着出现封面小图。
- **project.html**：规格行（№ · 年份 · 类别）、大标题、灰色副标题；封面放在圆角卡片里，右上角坐着这个作品的小物件（轻轻浮动）；_THE STORY 文字（第一段大字）；_GALLERY 两栏图片卡片（视频静音自动播放）；最下面深色 "NEXT TOY" 卡片。
- **about.html**：Version 1 原文，按重要程度排：最重要的话大字，句子里坐着小玩具，"overwhelming things feel less overwhelming" 用黄色荧光笔高亮；三张白色卡片（Where it started / How I make / How I lead）；最后一句大字 + 黑色 GET IN TOUCH 按钮。没有跳到作品的链接，约 1.7 屏看完。
- **PLAY AREA**：还没有，导航里是灰色（光标显示 COMING SOON）。
- 每个页面左下角有**青蛙向导**，会说一句提示（点它会换一句、跳一下）。
